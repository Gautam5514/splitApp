# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately via GitHub: **Security → [Report a vulnerability](https://github.com/Gautam5514/splitApp/security/advisories/new)**, or email `support@splitease.app` with the subject "Security".

Include what you found, steps to reproduce, and the potential impact. We aim to acknowledge reports within 5 days.

## Scope

Anything in this repository: the mobile app, its auth flow, handling of tokens and payments/UPI links, and deep links. Please don't test against other users' accounts or production data.

## Secrets

If you spot a committed credential, report it the same way rather than opening an issue.
